============================================================
1. WHAT WAS IMPLEMENTED
============================================================

- Admin Dashboard (/app/admin) with summary cards and recent
  admin activity.
- User Management (/app/admin/users): paginated/searchable/
  filterable user table, create/edit dialogs, role change,
  activate/deactivate with confirmation dialogs.
- Password management: Admin changes a user's password; bcrypt
  hash replaced; refresh sessions revoked; audit event.
- Last-admin protection: deactivating or demoting the final
  active ADMIN is rejected with 409.
- Admin-only Audit Logs page (/app/admin/audit-logs): filters
  (action, entity type, date range, search), pagination,
  detail dialog; access itself audited as AUDIT_LOG_VIEWED on
  first-page requests.
- System page (/app/admin/system): safe overview (name, API
  version, environment, version, DB connectivity, counts, users
  by role). No secrets exposed.
- Admin sidebar expanded: Dashboard, Users, Datasets,
  Indicators, Reporting Periods, Audit Logs, System.
- Admin dashboard kept distinct from Manager analytics.
